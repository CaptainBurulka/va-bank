# Ва-банк

Карткова дуель для двох у нічному підпільному казино. Мобільна веб-гра (PWA) для iPhone: два гравці на двох телефонах, гра проти бота або «передай телефон» на одному пристрої.

**Лише віртуальні фішки.** Жодних реальних грошей, покупок чи реклами.

## Як грати з телефона

1. Відкрий сайт гри в Safari (адреса GitHub Pages: `https://<користувач>.github.io/<репозиторій>/`).
2. «Поділитися» → «На початковий екран». Тепер гра запускається на весь екран, як застосунок.
3. Режими:
   - **Створити кімнату**: з'явиться код із 4 літер. Передай його другу (кнопка «Поділитися кодом» надсилає посилання, яке одразу відкриває вхід у кімнату).
   - **Приєднатися за кодом**: введи код і натисни «Підключитися».
   - **Гра проти бота**: щоб пограти наодинці.
   - **Передай телефон**: двоє на одному телефоні. Перед кожним ходом з'являється шторка, щоб суперник не підглянув карти.

Звук вмикається після першого дотику до екрана (так вимагає iOS). Вимкнути звук можна в меню ☰ під час гри.

## Правила

**Мета.** Забрати всі фішки суперника або мати більше фішок після 12 раундів. На старті в кожного по 100 фішок.

**Колода (33 карти).** Значення 1–10 у трьох мастях (💧 Вода, 🔥 Вогонь, 🪨 Камінь) і 3 спецкарти.
- Перемагає більше значення. Якщо значення рівні: Вода б'є Вогонь, Вогонь б'є Камінь, Камінь б'є Воду.
- 🔪 **Ніж**: сила 0, але б'є будь-яку десятку.
- 🪞 **Дзеркало**: копіює значення й масть карти суперника, тому завжди нічия.
- ×2 **Подвоєння**: сила 5. Якщо перемагає, програвший додатково доплачує суму, рівну банку (скільки має).

**Раунд.**
1. **Анте**: кожен ставить 5 фішок у банк.
2. Кожен добирає карти до 4 у руці.
3. Обидва одночасно й таємно кладуть по одній карті сорочкою догори. На це 20 с, інакше ляже випадкова карта.
4. **Розвідка**: кожен може один раз заплатити 4 фішки в банк і побачити **масть** (не значення) карти суперника. Суперник бачить, що за ним підглядали. Якщо це спецкарта, побачиш лише «спецкарта».
5. **Торги**: першим ходить той, хто програв минулий раунд. Варіанти: Чек / Підняти (+5, +10 або ва-банк) / Пас. На підняття можна відповісти: Колл / Ре-рейз / Пас. Максимум 2 підняття за раунд. Пас: суперник забирає банк без розкриття.
6. **Розкриття**: переможець забирає банк. При нічиїй банк переходить у наступний раунд.
7. **Подвій або нічого**: переможець може вгадати, буде верхня карта колоди **більшою** чи **меншою** за його зіграну карту. Вгадав: виграш ×2 (доплачує суперник). Не вгадав: увесь виграш забирає суперник. Можна до 2 разів поспіль. Суперник бачить усе наживо.
8. Після пасу або перемоги можна показати свою карту, щоб похизуватися блефом.

**Кінець.** Хто збанкрутував, той програв. Після 12-го раунду перемагає той, у кого більше фішок.

## Ухвалені дрібні рішення

Усі числа балансу лежать у [`config.js`](config.js).

| Питання | Рішення |
|---|---|
| Хто ходить першим у 1-му раунді | Випадково (crypto RNG хоста). |
| Хто ходить першим після нічиї | Той самий гравець, що й у попередньому раунді. |
| Колода закінчилась | Відбій перетасовується в нову колоду. |
| «Подвоєння» проти 5 / Ніж проти Дзеркала | Нічия (рівна сила, а мастей у спецкарт немає). |
| Розвідка спецкарти | Видно лише «спецкарта», без назви. |
| Розмір ва-банку | Усе, що лишилось після колу, але не більше, ніж має суперник. Більше піднімати немає сенсу, бо суперник не зможе відповісти. |
| Ліміт піднять | 2 на раунд сумарно для обох гравців. |
| Таймер у торгах | 25 с на хід. Після тайм-ауту автоматично чек, а якщо треба доставити фішки, то пас. Розвідка: 12 с, потім пропуск. Екран результату: 20 с. |
| «Виграш» у «подвій або нічого» | Усе, що переможець отримав за раунд (банк плюс штраф «Подвоєння»). Подвоєння оплачує суперник у межах того, що має. Якщо в нього вже нічого немає, подвоювати далі не можна. |
| Рівне значення в «подвій або нічого» | Програш. Відкрите «Дзеркало» дорівнює твоїй карті, тобто теж програш. Ніж = 0, «Подвоєння» = 5, твоє Дзеркало = значення карти суперника. |
| «Подвій» після пасу суперника | Дозволено, але твоя карта при цьому розкривається, бо від неї відраховується «більше/менше». |
| Хизування | Показати можна лише нерозкриту карту (після пасу), і це може зробити будь-хто з двох. |
| Банкрутство при перенесеному банку | Якщо після нічиї в гравця 0 фішок, але банк не порожній, гра триває: банк ще можна виграти. |
| Нічия в 12-му раунді | Банк ділиться навпіл. Непарна фішка дістається тому, в кого менше фішок. |
| Вдалий блеф | Суперник спасував, хоча твоя карта програвала б йому. Ця статистика прихована до кінця партії, бо інакше розкривала б карти. |
| «Передай телефон» | Таймери вимкнено. На екрані результату карти в руці приховано. Програвший у розкритті автоматично натискає «Далі». |
| Реванш онлайн | Нова партія починається, коли обидва натиснули «Реванш». Бот погоджується завжди. |
| Вихід через меню | Онлайн-кімната закривається для обох. Кнопка «Продовжити кімнату» в меню потрібна на випадок, коли iOS сама вивантажила сторінку. |
| PeerJS | Лежить у `vendor/` (v1.5.4, MIT), щоб не залежати від CDN і працювати з кешу service worker. |

## Архітектура

```
config.js        баланс
game/            чиста логіка без DOM і мережі
  cards.js       колода, порівняння, значення
  engine.js      стан, правила, reducer дій, viewFor() (що бачить кожен гравець)
  bot.js         бот; приймає лише view, тож не підглядає
net/
  host.js        GameHost: хост-авторитетна сесія, таймери, пауза, збереження; BotSeat
  protocol.js    версія протоколу, валідація повідомлень, коди кімнат
  online.js      PeerJS: кімната хоста, гість, серцебиття, перепідключення
ui/              рендер, анімації (CSS 3D), Web Audio-звуки, тексти
sw.js            офлайн-кеш (бот і «передай телефон» працюють без мережі)
```

**Безпека інформації.** Уся логіка, колода й рандом (`crypto.getRandomValues`) живуть на хості. Гість надсилає лише дії (`{v, type:'action', action}`). Хост перевіряє версію протоколу, відкидає зайві поля, а гравця визначає за з'єднанням, а не за вмістом повідомлення. Потім валідує дію reducer-ом. Кожному гравцю хост шле тільки `viewFor(state, seat)`: карт суперника там немає ні в руці, ні на столі до розкриття. Це перевіряють автотести. Хост-гравець технічно має повний стан у своєму браузері, адже в хост-авторитетній моделі хосту доводиться довіряти.

**Перепідключення.** iOS рве WebRTC, коли блокується екран або згортається Safari.
- Обидві сторони обмінюються ping кожні 2 с. Після 7 с тиші з'єднання вважається втраченим.
- Хост ставить таймери на паузу, а в обох з'являється «Суперник не на зв'язку».
- Гість перепідключається до того самого коду з наростаючою затримкою і пред'являє свій токен.
- Хост зберігає партію в `localStorage`. Якщо iOS вивантажила сторінку, у меню з'являється «Продовжити кімнату XXXX»: хост знову реєструє той самий код, гість повертається через «Повернутися в кімнату» і отримує повний стан.
- Сторонній гравець без токена в почату партію не потрапить.

## Розробка і перевірка

```bash
npm test                      # 31 автотест логіки, бота і протоколу (node --test)
npm run serve                 # локальний сервер http://localhost:8080
node tests/e2e/play.cjs bot   # e2e через Playwright: повна партія з ботом
node tests/e2e/play.cjs hotseat
node tests/e2e/online.cjs     # два «телефони» з імітацією PeerJS: обрив зв'язку, перезавантаження, реванш
```

Іконки генеруються скриптом `python3 tools/make-icons.py` (потрібен Pillow).

Щоб перевірити з телефона в локальній мережі: `npm run serve` і відкрити `http://<IP-комп'ютера>:8080`. Service worker і «На початковий екран» повноцінно працюють лише через HTTPS, тобто на GitHub Pages.

## Деплой

Workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) запускає тести і публікує гру на GitHub Pages під час push у `main`. Один раз увімкни в репозиторії: **Settings → Pages → Source: GitHub Actions**.

Після оновлення гри збільш `CACHE` у `sw.js`, щоб телефони точно отримали нову версію. Без цього нова версія підтягнеться з другого запуску.
